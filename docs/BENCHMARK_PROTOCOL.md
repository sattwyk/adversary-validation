# Benchmark protocol

1. Validate metadata and primary provenance. Acquire full commits; verify tree hashes and direct-parent pairs. Review that the fix actually removes the mechanism. Parent selection is a comparison convention, not proof all earlier releases are vulnerable.
2. Prepare independent vulnerable/fixed directories with the same toolchain, dependencies, configuration and instrumentation. Keep upstream licenses. Save source/tree hashes, compiler output, architecture, kernel, libc, filesystem/mount/device, environment and build flags. Missing locks block a reproducible run.
3. Run the unmodified native baseline first. A passing upstream test establishes only that fixture. Source-added regression tests absent from the parent need a separately hashed test-only patch, checked for API compatibility. Never transplant production code from the fix.
4. Seal ordinary workload, fault envelope, oracle and budget. Freeze policy and seeds before pair testing. Distinguish REPRODUCTION, REDISCOVERY, BLIND REDISCOVERY and BASELINE in every artifact. Reproduction inputs live outside the search package.
5. Negotiate capabilities before running. A missing shared cursor, concurrency, namespace or transport behavior yields MODEL CANNOT REPRESENT REQUIRED BEHAVIOR. Never serialize/simplify it away to get a green result.
6. Execute the same bounded campaign on both revisions, equal limits, paired seeds and fresh isolated state. Record cold build cost separately from execution/search/replay. Include failures, interrupted runs and unsupported targets.
7. Validate evidence before judging the target. Check trace/history grammar, oracle reachability, fault admissibility, fair recovery interval and controls. Independent reviewer distinguishes infrastructure bugs from target bugs.
8. Preserve original counterexample and replay; reduction is a new artifact with a link to the original. Require the causal chain in COUNTEREXAMPLES.md, then review historical correspondence. Independently native-confirm where possible.
9. Report gates, capabilities, attempts, time-to-first-failure, censorship, diagnosis limits, costs and controls. No passing result silently replaces a failed or unfinished one.

Safety holds at every admissible observed prefix. Liveness is checked only after faults cease: all configured nodes needed for convergence are running, a quorum connects, messages/IO and runnable tasks receive finite progress, time advances. Default grace is 20 maximum configured election timeouts plus completion of 100 client writes; record the actual timeout and fairness bound. A host watchdog catches a stuck harness and has no automatic target liveness meaning.

Negative controls include fixed historical source pairs, valid/invalid oracle histories, a known-correct sequential register fixture, deliberately incapable capability declarations and recorder/controller artifact fixtures. See controls/README.md. A planted history tests the checker only, not an upstream implementation. Controller-induced deadlock is separate from target liveness.

Historical dependencies without lockfiles must be resolved once in preparation, retained with checksums and frozen for both runs. If equal dependency solutions are impossible, disclose the confound and withhold fair discrimination. Exact native commands are reviewed but only enabled after dependency/toolchain preparation. Source-only rows retain an investigation checklist.

Ordinary workload JSON contains numerical timer configuration independently of upstream regression fixtures. OpenRaft uses 300–600 ms elections and 100 ms heartbeat intervals; etcd uses 100 ms ticks, election ticks 10 and heartbeat ticks 1; HashiCorp uses 1000 ms heartbeat/election and 500 ms leader lease, retaining its existing timeout jitter. During fault-free recovery, every continuously enabled task or submitted IO/delivery progresses within 1000 selected eligible events; a due timer is subject to the same bound. Measure the maximum timeout including upstream jitter when computing the 20-timeout grace. A future adapter must map and audit these public configuration values without altering algorithms. No ordinary search driver is implemented here.

Storage workload F sets the existing public SegmentSizeBytes variable to 65536 before WAL creation and writes 256 4096-byte entries with monotonically advancing committed hard state. This is workload configuration, not a line-specific rotation or crash failpoint. J's unfenced-tail byte-prefix profile is declared logical behavior; native acceptance still requires the independent qualification specified in MODEL_REQUIREMENTS.md.

All actions and faults apply to isolated local sources, disposable target data or owned toy fixtures. No live third-party system is in the execution scope.
